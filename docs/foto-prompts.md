# NOVA X – Foto-Prompts (nur Bilder)

Der Spot wird aus Standbildern gebaut. Ich animiere sie mit Kamerafahrten, Parallax-Ebenen, Lichtkanten, Zeitlupen-Zoom, Filmkorn und Schnitten auf den Beat.

## Einstellungen im Generator
- Format **16:9**, so groß wie möglich (ideal **2560×1440** oder mehr, damit ich ohne Qualitätsverlust hineinzoomen kann)
- Wenn möglich: **dein Schuhfoto als Referenzbild** hochladen und bei allen Bildern denselben Stil oder Seed verwenden
- Pro Prompt **2–3 Varianten** erzeugen
- Kein Text, keine Logos (steht schon in den Prompts)
